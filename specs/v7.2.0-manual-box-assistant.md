## 1. Intent

Shift from auto-detect RBR/DBD boxes to a manual-assistant model: user draws
rectangles manually, tool colorizes by S-scale. Refine 8-handle UX and add a
floating color palette (TradingView-style).

* **Objective**: toggle for auto-detection, auto-color by scale, refined handles,
  floating palette (2 color controls + 1 opacity slider).
* **Non-Goals**: backend/Rust, RBR/DBD detection logic, BoxOverlay, magnet logic,
  candle colors, display-mode toggle, routing, docs.

## 2. Contracts (Part E data model)

```typescript
interface DrawingRect {
  id: string; type: "rectangle";
  ts_start: number; ts_end: number;
  price_low: number; price_high: number;
  borderColor: string; fillColor: string | null; fillOpacity: number;
  lineWidth: number; selected: boolean;
  // legacy compat: color? fill?
}
```

Migration: `color` → `borderColor`, `fill` → `fillColor` (+ parse opacity),
`fill: null` → `fillColor: null, fillOpacity: 0`.
Persist: `localStorage` key `vora.drawings.<symbol>`.

## 3. Implementation

1. Part A — `autoDetect` state in ScaleLabPage (persist `vora.policy.autoDetect`,
   default true); PolicyPanel checkbox at top; detection effect guards on it.
2. Part B — `autoColorForRect()` helper in `rectInteraction.ts`; wired in
   `useRectTool.ts` second-click BEFORE push.
3. Part C — `RectangleOverlay`: circles for corners (r=4), 6×6 squares for
   middles, visibility on border/handle hover or selection (not interior hover),
   blue (#2962ff) outlines while hovered and blue-filled handles while selected.
   Keep the rectangle border color and width unchanged on hover and selection.
   Only the visible border and eight handles select an unselected rectangle;
   after selection, dragging its interior or border moves the whole rectangle,
   while handles edit anchors.
4. Part D — `RectColorPalette.tsx`: 2 color controls + 1 opacity slider,
   8-color swatch row, top-center ±8px flip, dark panel styling.
5. Part E — rename + migration + persist. Part F preserved.
