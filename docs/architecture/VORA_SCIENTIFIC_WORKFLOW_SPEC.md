# Scientific Workflow Spec

## Workflow A — Discovery from zero

Observation -> Raw Idea -> Research Planning -> Research Gap -> Question -> Hypothesis -> Experiment Design -> Preregistration -> Experiment Run -> Dataset -> Dataset Version -> Analysis Run -> Evidence -> Finding -> Scientific Evaluation -> Model Candidate -> Model Version -> Validation -> Real-world Application -> Feedback -> New Research Cycle

Requirements:

- preserve source references and project ownership
- maintain parent-child lineage
- keep actor and AI/human origin explicit
- preserve uncertainty and contradictory evidence

## Workflow B — Understanding an existing model

Existing Model -> Source Collection -> Source Version Pinning -> Model Decomposition -> Assumption Extraction -> Concept and Relationship Mapping -> Evidence Assessment -> Reproduction -> Validation -> Mastery Assessment -> Documented Understanding

Requirements:

- distinguish claims from independently verified findings
- retain contradictions and unresolved assumptions
- preserve original model lineage

## Workflow C — Evolution of an existing model

Existing Model Version -> Baseline Assessment -> Limitation Identification -> Improvement Proposal -> New Hypothesis -> Experiment Design -> Experiment Run -> Comparative Analysis -> Evaluation -> Improved Model Candidate -> Version Branch -> Validation -> Real-world Feedback -> New Version

Requirements:

- preserve original model and all prior versions
- allow branching and rollback
- require explicit adoption or rejection of new versions
