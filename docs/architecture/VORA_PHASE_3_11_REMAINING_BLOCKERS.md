# VORA Phase 3.11 Remaining Blockers

- Live third-party VS Code MCP tool invocation was not performed.
- Live restore against a human-managed disposable database was not performed.
- Multi-project GUI switching was not tested after cleanup.
- Native Windows symlink/junction behavior depends on environment privileges and is not fully human-accepted.
- Main product Rust/Tauri domains remain unmigrated.
- Electron packaging/updater/sidecar parity remains incomplete.
- Legacy database schema mappings for scientific, provenance, visual, and media domains remain unresolved.
