- The existing Workspace footer displays Electron runtime status.
- Tauri drag-drop and updater listeners are disabled when Electron runtime is detected.

- Smoke mode executes runtime IPC from the real Renderer and closes cleanly.

- The existing UI can render in Electron, but Tauri-dependent functionality is unavailable until adapters are added.
